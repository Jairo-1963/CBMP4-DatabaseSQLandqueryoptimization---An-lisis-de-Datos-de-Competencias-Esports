# 🗄️ Database SQL and Query Optimization

Repositorio correspondiente al módulo **CBMP4 – Database SQL and Query Optimization**, enfocado en el diseño de bases de datos relacionales, consultas SQL avanzadas y optimización del rendimiento.

## 🎮 Proyecto: eSports Database

Proyecto final orientado al modelado y análisis de una base de datos para una plataforma de eSports, gestionando información de jugadores, equipos, torneos y resultados.

## 🎯 Objetivo del proyecto
Diseñar una base de datos relacional eficiente y aplicar técnicas de optimización de consultas SQL para mejorar el rendimiento y la calidad del análisis de datos.

## 📚 Contenidos y actividades
- Diseño de modelo relacional
- Creación de tablas y relaciones
- Consultas SQL básicas y avanzadas
- Uso de JOINs y subconsultas
- Creación de índices
- Optimización de consultas
- Análisis de rendimiento en MySQL

## 🛠️ Tecnologías utilizadas
- MySQL
- SQL
- MySQL Workbench
- Modelado relacional
- GitHub

project/ → Script final del proyecto
